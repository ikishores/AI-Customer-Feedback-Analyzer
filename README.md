# AI-Customer-Feedback-Analyzer

🧠 Intelligent Customer Feedback Analysis System using AI
🌟 Overview

Customer feedback is the heartbeat of any business — but reading thousands of reviews manually isn’t practical.
This project uses Artificial Intelligence to automatically analyze, summarize, and predict sentiment from customer feedback collected through multiple channels like emails, chat logs, and social media comments.

Built using Python, Streamlit, and AI/NLP models, this system helps companies make faster, data-driven decisions based on real customer opinions.

🚀 Key Features

✅ Sentiment Analysis – Understand whether customer feedback is positive, negative, or neutral using NLP models.
✅ Feedback Summarization – Automatically generate concise summaries of large text datasets.
✅ Predictive Insights – Forecast customer satisfaction trends using Facebook Prophet.
✅ Interactive Dashboard – Visualize trends, word clouds, and sentiment distributions with Streamlit UI.
✅ Data Preprocessing – Clean and preprocess raw data for smooth AI model performance.

⚙️ Installation & Setup

1️⃣ Clone the repository

git clone https://github.com/ikishores/AI-Customer-Feedback-Analyzer.git
cd AI-Customer-Feedback-Analyzer/src


2️⃣ Install dependencies

pip install -r requirements.txt


3️⃣ Run the app

streamlit run app.py


4️⃣ Open your browser at http://localhost:8501
